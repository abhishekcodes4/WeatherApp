# 🌦️ Weather App

A simple and responsive Weather App built using HTML, CSS, and JavaScript. It uses the OpenWeatherMap API to fetch weather information for different cities.

## ✨ Features

- 🌍 Search weather by city name
- 🌡️ Display current temperature
- ☁️ Show weather conditions
- 💧 Display humidity
- 💨 Show wind speed
- 📱 Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeatherMap API

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/abhishekcodes4/WeatherApp.git
   ```

2. Open the project folder in VS Code.

3. Configure your OpenWeatherMap API key according to the project's configuration.

4. Open `index.html` using Live Server or another local web server.

## 🔐 API Configuration

This project requires an OpenWeatherMap API key.

**Security note:** Do not commit your personal API key to a public repository. A key used directly in frontend JavaScript can be visible to visitors. Restrict the key where supported or use a backend proxy.
